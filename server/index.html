01 QB FEATURED · YOU ARE ON IT

queenbee-core-srv — Self-Hosted Server

A production-grade home server built on repurposed hardware and a hardened Linux install — the machine serving this page right now. Every layer was configured, secured, and debugged by hand: key-only SSH with root login disabled, a default-deny ufw firewall, fail2ban, and zero ports opened on the router. Ingress flows through a zero-trust Tailscale network with public HTTPS via Let's Encrypt, into an Nginx reverse proxy that routes to Docker containers built with multi-stage builds. Services are managed by systemd with restart policies, so the whole stack self-heals after a reboot or power cut.

  • Zero-trust networking: CGNAT-proof public ingress without a single port-forward
  • Full request path owned end to end: HTTPS → Nginx → Docker → app
  • Debugged in production: SSH auth, port conflicts, proxy 502s, container lifecycle
